# НАПОМИНАНИЕ: Ограничение работы мода только на конкретном сервере

По запросу владельца, необходимо будет реализовать защиту, чтобы данный мод ("project3") работал исключительно на его сервере.

## Запланированные варианты реализации:

1. **Проверка по лицензионному ключу**:
   - При запуске на сервере мод проверяет наличие и содержимое файла `config/server_key.txt`.
   - Ключ сравнивается с секретным хэшем. Если совпадения нет — мод отключает все свои механики (квесты, производители, границы, аномалии) или останавливает сервер.

2. **Проверка по IP/домену на стороне клиента**:
   - Клиентская часть мода проверяет адрес текущего сервера (`client.getCurrentServerEntry().address`).
   - Если игрок зашел на чужой сервер или в одиночную игру, HUD, компас и другие визуальные элементы отключаются.

**Текущий статус**: Временно отложено по решению пользователя. Реализовать при первом запросе.
